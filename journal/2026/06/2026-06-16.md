## Iroh 1.0 — Dial keys not IPs，95% direct peer connections 跨 200M endpoints

6/15 release，HN 950 點 285 留言衝上首頁。Iroh 是 Rust 寫的網路 library，核心句「**Dial keys. Not IPs.**」——把裝置定址從不穩定的 IP 翻成 **cryptographic key**，跨防火牆 / NAT / 路由器漂移 / Wi-Fi 切 4G 全部 transparent。1.0 保證 wire protocol + API 跨 minor version 穩定，官方支援 **Python / Node.js / Swift / Kotlin** 四個 binding 跟 Rust 平行（過去 0.x 系列只有 Rust）。實測指標：過去 30 天公開 relay 上 **200 million endpoints 建立**、**~95% 達成 direct peer connection**（剩 5% 才需要 relay 中繼），對 Henry 你 Nexus 客戶交付「設計 token 跨 designer ↔ engineer round-trip」這條工作流，第一次有正式 1.0 protocol 可以在不靠雲端中介的情況下做 P2P 同步。

技術機制三層：**QUIC multipath** 在單一 connection 內管多條 route（4G 跟 Wi-Fi 同時開、誰先到用誰）、**QUIC NAT traversal** 透過 STUN-style 打洞建直連，**custom transport** 同時支援 Bluetooth / LoRa / WiFi Aware / Tor 任何能傳 bit 的底層、**WASM compile target** 讓瀏覽器也能跑 Iroh endpoint 不必裝原生套件。public relay 0.35x 系列已宣布 deprecation timeline 走到 2026-12，自架 relay binary 全 open source 給企業 deploy 不必依賴 Iroh 官方 server。**95% direct peer connection 跨 200M endpoints** 不是 demo 數字而是 production traffic——背後是 millions of devices 真實在用 Iroh 1.0 的 protocol。對應 5/13「界線重劃」洞察 DuckDB Quack 把「in-process only」邊界拆掉、Statewright 把「agent 該不該用某工具靠 prompt 約束」邊界拆掉的下一檔：**「裝置之間要連線一定走 server 中介」這條 25 年的網路假設第一次被拆**。

Before：你跟同事跨地點同步 Figma token JSON，必須走「Figma cloud → GitHub PR → CI/CD → Vercel preview」四跳 round-trip，每跳延遲、每跳資料留在第三方，企業客戶常擔心商業機密設計 token 從 cloud 漏出；After：Iroh 1.0 + 一段 Rust 或 Python script，你跟同事的 MacBook 之間 **直接** 用 cryptographic key 對 dial，95% 機率走 direct connection 不經任何第三方 server，token JSON 從你的 packages/ui/tokens.json 直接同步到對方 file system，所有運算留本地零 cloud egress。對 Henry Nexus 三件可動：(1) `packages/nexus-token-sync` 拿 Iroh Python binding 做「dial key 跨 designer/engineer round-trip token JSON 即時同步」 PoC，**對應 Henry 6/8 Linear local-first 架構洞察** 把 local-first 從 client-side state 拓展到 cross-device 同步層；(2) Nexus 客戶採購 deck 加「資料不出本地網路」差異化賣點對應 6/10 Mythos 5/Fable 5 拆分後 vendor lock-in 顧慮上升的客戶情緒；(3) `~/.claude/skills/` 之間想要跨機器同步 Claude_auto 學習脈絡，Iroh 1.0 比過去用 git remote 同步多出「私人 cryptographic key + 95% direct」兩個工程優勢——對應 6/11 Zed DeltaDB CRDT worktree 人+agent 共編檔案那條洞察的網路層補位。

## Typst 0.15.0 — Variable font axes 升格 first-class token + Bundle export 把 SSOT 拓展到多檔案輸出

6/15 release。Typst 是 Rust 寫的開源 typesetting 系統（對標 LaTeX），0.15.0 主要結構性變更兩件：(1) **Variable font 完整支援**：自動套用標準 variation axes（weight / style / stretch / size）+ 開放 `variations` 參數讓你顯式指定 axis 值，不再是「指定 font-weight: 600 然後 fallback 到最近的 static font」；(2) **Bundle export** 實驗性功能——「a single Typst project can output multiple files（e.g. a multi-page website）」一份 source 可以同時輸出 PDF + 多頁網站 + EPUB 等不同 format。同時 MathML 在 HTML export 自動帶上（accessibility + 語意保留）、多 bibliography 配置、`within` selector 簡化 introspection、spot color 印刷專用 pigment。Henry 你 Figma → JSON → OKLCH Token → Angular 工程鏈，第一次有 typography 端的對標可以借鑑——**variation axis 升格 first-class token** 跟你色彩主題已經用 OKLCH 三軸（L/C/H）描述同一條哲學。

技術機制：variable font（OpenType 1.8 規格）原本就把字型的「weight 從 100 到 900 連續可調 + width 從 condensed 到 expanded 連續 + optical-size 隨字級自動調整」變數化，但過去多數設計系統把它當「font-weight: 600 反查最近的 static font」用。Typst 0.15.0 把這四個 axis 升格為 source layer 第一公民——你寫 `#set text(weight: 437, width: 92%, optical-size: 14pt)` 就直接套用 variable font 內建插值，不存在 fallback。Bundle export 把「一份 source 多種輸出 target」的概念從 LaTeX 多年來「跑兩次 latex/pdflatex/xelatex 各自生不同檔」推到「一次跑出 multi-file site」——對應 Nexus packages/www docs 一份 MDX source 同時輸出網頁 + PDF 手冊 + EPUB 客戶交付文件的需求。MathML 在 HTML 自動帶上對應 5/16 dev.to「單次 AI code review 抓不到一半 bug」洞察 — 結構化資訊保留是後續 AI agent 能不能讀懂的關鍵，「方程式轉成圖片」這條過去做法在 LLM era 直接讓 agent 看不見內容。

Before：你 Nexus 設計系統 token 只覆蓋色彩（OKLCH 三軸 L/C/H）+ 間距（rem-based scale）+ radius/shadow——typography 那層只能寫死 `font-weight: 400 / 500 / 600` 三個 enum value 套不同 static font 檔案；After：variable font axis 升格 first-class token 之後，你的 Figma JSON 可以宣告 `font.weight.brand-primary: 437`（不是 enum 而是連續 value）+ `font.width.headline: 92%` + `font.optical-size.body: 14pt`，CSS Custom Properties 直接 `--font-weight-brand: 437` 對接 variable font CSS 規格（`font-variation-settings: "wght" var(--font-weight-brand)`）——一份 token JSON 從色彩 → 間距 → typography 全覆蓋。對 Henry Nexus 三件可動：(1) `packages/ui/tokens/typography.json` 加入 weight/width/optical-size 三個 axis variable token 對標 OKLCH 模式，從 Figma JSON 拉出來自動同步 CSS Custom Properties；(2) `packages/www` docs build chain 對標 Typst Bundle export 概念，把 MDX source 一次輸出網頁 + PDF + EPUB 三 target（Nexus 元件文件給設計師看網頁、給法務看 PDF、給離線客戶看 EPUB）；(3) Storybook 加 variable font axis playground，設計師調 axis value 直接看 token JSON 變動，對應 6/7 Jane Street 「working prototype 取代 Figma frame」洞察的 typography 層補位。

## 今日總結

四件事在同一個工程動作上交集：**「邊界」第一次能帶參數**——Claude Code v2.1.178 的 `Tool(param:value)` 把 permission 從工具名升到工具+參數契約、Iroh 1.0 的 cryptographic key 把網路定址從 IP 升到可移植 key + 95% direct peer connection、LinkedIn npm `prepare` 後門攻擊鏈把「我看你 repo 一眼」這條社交工程入口要求升到必須先 sandbox 的契約、Typst 0.15.0 的 variable font axis 把 typography token 從 enum value 升到連續 value axis。
