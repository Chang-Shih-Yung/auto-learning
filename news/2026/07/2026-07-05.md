# 2026-07-05 AI 世界新聞

## Cambridge Judge Business School 2026 全球金融業 AI 報告 — 52% 金融機構正在導入「自主執行多步驟交易的 AI agent」

**發生了什麼**：Cambridge Judge Business School 底下的 Cambridge Centre for Alternative Finance（CCAF）4 月做完的全球金融業 AI 調查在 7 月初把完整報告攤開——**52% 受訪金融機構正在導入 agentic AI**（可以連續執行多步驟工作流的 AI 系統）當作最快成長類別，其中詐欺偵測（58%）與信用風險模型（54%）在風險與合規應用中領先。這是第一次「AI 不只是輔助人做決策，而是自己執行整條決策鏈」在金融業出現多數普及的證據。過去談 AI 金融應用永遠停在「分析師用 AI 找訊號、人做決定」，這份報告記錄的是 KYC/AML 合規自動化、即時支付監控、後台文件處理都已直接由 AI agent 完成，人只在中途高風險節點介入。

**技術怎麼運作**：agentic AI 跟過去「chatbot 或 ML 模型」的差別在「連續決策」——過去的模型輸入一筆資料吐一個分類結果（這筆交易有沒有詐欺、這個客戶信用分數多少），agent 系統是輸入一個目標（「今天下班前完成這 500 筆 KYC 覆核」）自己拆解成多個小步驟：先撈資料、比對客戶自報 vs 政府開放資料、有疑點自動送查名單、疑點消除後自動歸檔、剩下無法自動解的排給合規人員。技術上是把大型語言模型當「推理引擎」+ 一組銀行內部工具（transaction database / 制裁名單 API / 內部合規表單）當「手腳」，模型自己判斷下一步該做什麼工具呼叫。這條路線 2024 年還在實驗室，2026 年 4 月 CCAF 調查時已 52% 金融機構在跑，成長速度快到報告中稱作「fastest-growing category」。

**對普通人的意義**：你現在打電話進銀行請客服開戶、追蹤一筆匯款、要求提高信用卡額度，等待時間平均要 3-7 天——因為背後 KYC/AML 合規流程是「人一筆一筆看」。agentic AI 普及之後這些延遲會壓到「幾小時內」甚至「即時」，因為 agent 可以連續跑幾百筆案件不用睡覺不用休息。但另一面：詐騙同時也更難識破——58% 銀行用 AI 做詐欺偵測代表你的每筆交易都在被 AI 打分，偽卡盜刷通常會被當場擋掉；同時你自己在網銀做「金額不尋常的轉帳」也更容易被 AI 判成可疑、需要多一層驗證。銀行運作正從「人為中心」翻「機器為主、人 review 邊緣案例」——服務更快、監控更嚴、隱私與人工申訴管道更窄，是這條主線同時發生的三件事。

## AI 量化交易顛覆華爾街：市場規模 $11.23B → $33.45B，個人投資者第一次用自然語言寫策略

**發生了什麼**：2026 年 2 月一份 Miami Today 報告揭露一個過去屬於高盛、Renaissance、Two Sigma 這種頂級量化基金的能力——用大型語言模型（Anthropic Claude 這類 AI）**用自然語言生成交易演算法、做回測、做風險管理**——正在被個人投資者跟中小型基金複製。全球 AI 交易平台市場規模 2024 年 $112.3 億美金、2030 年預估到 $334.5 億美金，年複合成長率 20%。過去要僱三個 PhD 花半年寫的策略，現在一個懂投資邏輯的個人用一段對話讓 Claude 直接生成 Python 策略碼、拉歷史資料做回測、生風險曲線——單槍匹馬做到過去只有機構才做得到的事。同時大型基金正在把 AI agent 部署到「production 交易系統」而非只是研究工具——實時吞吐 tick 資料、新聞、另類訊號，在嚴格 latency 跟合規邊界內自動下單。

**技術怎麼運作**：LLM 之所以能生策略是三件技術匯流——(a) LLM 對金融時間序列、Python pandas、回測框架 backtrader/vectorbt 這些庫的訓練資料已經很完整；(b) 對話式生成 code 已達到可跑不用大幅改的品質；(c) 回測工具本身已 SaaS 化（QuantConnect / Alpaca / Nautilus Trader 這類平台），使用者不用自己架環境。個人投資者的流程變成「跟 AI 說『我想試三日均線黃金交叉搭 RSI 過熱指標策略，資金 10 萬美金，最大回撤限制 15%』」→ AI 生 Python 策略碼 → 平台跑 5 年歷史回測 → 出勝率、報酬、最大回撤圖表 → 修參數 → 重跑。過去這一整套流程要三個月，現在一小時。機構端則把 AI agent 塞進 production——每支 agent 對應一種市場條件（趨勢市 / 震盪市 / 事件驅動）自動切換、對照即時新聞跟 alt data 執行秒級決策、決策全部有 audit log。

**對普通人的意義**：以前「量化交易」是華爾街專利、需要千萬美金起跳建 co-location 機房 + 全職團隊——一般人根本進不去、只能買公募基金付 2% 管理費讓別人代操。今天你有 3 萬美金存款、有基本投資知識、願意花幾個週末學回測概念，就能用 $20/月 SaaS 平台加 AI 對話寫策略、在自己的 IB 券商帳戶跑——過去的護城河（模型能力 + 資料存取 + 執行速度）在「模型能力」這一邊被砍掉一大塊。同時風險也真實：AI 生的策略很多在歷史資料上看起來漂亮、在真實市場崩盤時死得很慘（過擬合），而**AI 不會告訴你哪些細節是它猜的**——你必須自己會判斷「這個策略是真的有邏輯、還是 AI 對過去五年資料 fit 得剛好」。金融「機會平等」跟「風險也平等」在同一件事上被打開。

## FINRA 2026 監理報告點名：AI agent「沒人在迴圈裡」、權限越界、資料誤用是三大新風險

**發生了什麼**：美國金融業自律組織 FINRA 6 月發布 2026 Oversight Report，把 AI 治理列為對 6,000+ 註冊券商的首要監理焦點。報告點名三個「新興 AI 風險」：**(1) AI agent 自主行動而「沒人在迴圈裡」（no human in the loop）**——過去監理假設每個下單、每筆申報都有人簽核，agent 系統打破這假設；**(2) agent permission/access 問題**——一個 AI agent 該能存取哪些內部系統？權限給太寬可能導致 agent 呼叫它不該呼叫的 API；**(3) AI 獨立誤用敏感資料**——agent 為完成任務可能組合客戶資料到未經授權的用途（例如把 KYC 資料用來訓練其他模型）。同時 FINRA 要求「Registered Investment Advisors 必須把 AI 系統當作和通訊、治理、文檔一樣嚴格的合規對象」——換句話說 AI 不能是「特殊灰色地帶」。這是美國金融監理**第一次針對 agentic AI 具體命名風險並要求對應治理**，跟 6 月才在 Cambridge 那份報告記錄 52% 機構已導入 agent 正好對照。

**技術怎麼運作**：FINRA 這份報告沒開新規則、開的是「舊規則怎麼套到 AI agent」的 gudiance。核心是三件檢查：(a) agent 的每個決策必須有可追溯 log——不是「AI 判斷過了」而是「AI 讀了哪些欄位、跑了哪個 prompt、產出哪個具體 output」；(b) agent 存取企業系統必須走 role-based access control（RBAC）——每個 agent 綁一個角色、角色綁權限，不能給 agent 「admin」這種寬權限；(c) agent 使用資料的目的必須跟原本收集資料的合規揭露一致——不能拿 KYC 資料訓練詐欺偵測模型除非揭露書寫過。技術上券商的 IT 團隊要做的是把 audit trail 從「人的動作」拓展到「agent 的動作」——每個 tool call、每個 API 呼叫、每個資料查詢都記錄，季度審計要能重現任一 agent 決策鏈。這條技術路線跟 Cloudflare 7/1 剛推的 x402 micropayment credential = payment 那條「agent 行為要有協議層 audit」洞察是同一條軸。

**對普通人的意義**：你在券商帳戶被 AI 系統誤標成「可疑交易」凍結、被 AI 拒絕貸款、被 AI 系統套用不利利率——過去這種決定翻案很難因為券商說「模型判定的」。FINRA 這份報告等於強制券商必須提供**可解釋、可追溯、可申訴**的決策鏈——你有權要求券商列出「模型讀了哪些資料、跑了哪個規則、為什麼判定 X」，人工申訴通道也必須存在。同時另一面：「沒人在迴圈裡」的風險被監理正視，代表銀行內部會加更多「重要決策必須人簽」關卡——你申請大額貸款、開立新型帳戶、做大額匯款可能會多幾個小時的人工核准延遲。監理的邏輯是「AI 快是好事，但重要決定不能全自動」——你享受 AI 帶來的效率同時，重要事情多幾步人工核准，是這個平衡的兩面。
